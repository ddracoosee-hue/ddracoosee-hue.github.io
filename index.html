How to Run Locally

Source code for these projects is private and available on request. Email me for access and I'll share the repository. Once you have access, follow the steps below. Commands are for Windows PowerShell unless noted.

Orion — http://localhost:3000
  • Node.js 22.13 or newer
  • A Gemini API key, or Ollama for fully local mode
  • A GPU is recommended for local inference
git clone https://github.com/ddracoosee-hue/Orion.git orion
cd orion
npm ci
Copy-Item .env.example .env
# Edit .env: add GEMINI_API_KEY, or set ORION_PROVIDER=ollama
# and build the local model with: npm run model:build
npm run build
npm start

# In a second terminal:
cd web
npm run dev

Open http://localhost:3000. Run npm run doctor to check the system's health.

Textclone — http://localhost:3000
  • Windows 11, Python 3.12, Node.js 20 or newer, Git
  • Ollama with the qwen3:14b model
  • An NVIDIA GPU is recommended
git clone https://github.com/ddracoosee-hue/textclone.2.git textclone
cd textclone
ollama pull qwen3:14b
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
powershell -ExecutionPolicy Bypass -File scripts\dev.ps1

Open http://localhost:3000. The local API runs on port 8000.

MicroCoin — Local 3000
  • Python 3.12 or newer
  • No API keys, network access or database server needed
git clone https://github.com/ddracoosee-hue/Microcoin.git microcoin
cd microcoin
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
.venv\Scripts\python -m memescout run
.venv\Scripts\python -m memescout health

The run completes against the built-in offline collector and prints its execution record.

Charizard — terminal app, Windows or macOS
  • Python 3.12 or newer
  • Setup installs the Chromium, Firefox and WebKit browser engines
# From the repository folder (macOS: ./bin/setup.sh and ./bin/charizard.sh)
.\bin\setup.ps1
.\bin\charizard.cmd doctor

# Start the bundled mock store to try it safely
.\bin\charizard.cmd mock-shop --port 8787

# Run the test suite
.venv\Scripts\python -m pytest

Every task starts in dry-run mode. Open the live console with charizard ui in a second terminal.

Orion

TypeScript | Model Context Protocol | DeepSeek + Gemini

Orion is a personal AI command center that pairs frontier-grade reasoning with full local control. Its inverted architecture limits language models to deliberation alone. They propose intentions, and Orion's own machine decides, executes and records every action. Control always flows outward, and no inbound port ever opens.

How it works

A composable "trunk" coordinates ten isolated, least-privilege subsystems. Every request passes through a hardened pipeline:

  • a tiered model gateway, with a custom-built local DeepSeek engine and Gemini handling sub-agents and context compaction
  • tool integrity hashes re-verified before every call
  • human approval for sensitive actions, denied automatically if unanswered
  • default-deny authentication
  • a tamper-evident, append-only audit trail

What it offers

A 66-tool arsenal across two sandboxed Model Context Protocol servers:

  • Durable, resumable sessions and a project system with layered memory and stage gates
  • A citation-grounded research pipeline and Obsidian knowledge-vault integration
  • An expandable skill library and an evolving user model that personalizes responses
  • Music control (Spotify, YouTube) and location intelligence from multiple providers
  • Hands-free conversation in Flow Mode, spoken in a custom-designed voice
  • Secure remote access through an outbound-only relay
  • The Celestial interface: a live node-graph canvas and neural-orb display showing each agent action as it happens

Why it stands apart

Architectural boundaries are enforced at build time. Nightly backups are integrity-checked, and a multi-tier diagnostic "doctor" audits the system. Orion is capable and also demonstrably trustworthy: an autonomous assistant built with enterprise-grade rigor for one private operator.

Textclone

Python | FastAPI | Next.js | Ollama

Textclone is a privacy-first, fully local AI writing engine. It learns your own writing voice and reproduces it closely. It ingests nearly any source: Discord, WhatsApp and iMessage exports, email, Word, OCR-processed PDFs, spreadsheets, slides, social media archives and web pages. A role classifier keeps only text you actually wrote.

From this corpus it builds a stylometric voice profile of about 90 linguistic features per sample. It detects register automatically (casual chat, academic essay, professional email) and records your signature vocabulary, the words you never use, and a style card for each register.

Its generation engine can rewrite text, write from a brief or draft replies. Each draft then passes a verification loop that checks factual fidelity, semantic preservation (BERTScore, EMD), length, syntax, punctuation, casing, vocabulary, pragmatics, perplexity-calibrated fluency, stylistic identity and AI-likeness. Every check is measured against targets taken from your own writing. The engine keeps repairing the text until it passes, never falls below its best version so far, and explains any shortfall.

An Analyze workspace scores any text for AI-likeness with a per-sentence heatmap. It combines local detectors, Binoculars scoring and linguistic tells, all calibrated to your personal baseline.

Textclone keeps learning: feedback and inline edits become new training data, an adversarial style classifier sharpens the voice match, and optional QLoRA fine-tuning trains a local model on your writing.

Everything runs on your machine, with no API keys, cloud services or subscriptions.

MicroCoin

Python | SQLite | Fault-Tolerant Pipelines

MicroCoin is a locally sovereign, read-only research platform designed to turn the chaotic, adversarial chatter of crypto communities into auditable, evidence-grounded intelligence. Its current release is the execution foundation that every research run is built on.

  • Orchestration. A bounded state machine drives each research run from start to completion, with every transition recorded.
  • Resilience. Lease-fenced local storage, crash-safe checkpointing and bounded budgets keep every run safe to interrupt, recover and resume.
  • Human approvals. Sensitive steps pause for an explicit decision: allow once, allow for the session, or deny.
  • Operations. Health, recovery, resume and cancel commands give full control over every run.
  • Offline by design. The pipeline runs end to end against a built-in offline collector, with no credentials, network access or LLM required.
  • Hardening. There are no wallets, trading or posting functions, by design.

Charizard

Python | Playwright | Browser Automation

Charizard is a cross-platform (Windows and macOS) browser agent that watches retail product pages and completes purchases for you. It stays strictly within spending limits you set in plain conversation, turning a frantic drop-day checkout into precise, accountable automation.

How it works

You perform a checkout once. Charizard records it as a portable playbook that identifies page elements by meaning rather than screen coordinates, so it replays identically on any machine or window size. A tiered decision engine judges every opportunity: buy automatically below your threshold, ask for approval in a middle band, and never buy above your ceiling. Hard daily, weekly, per-order and quantity caps always take priority.

What it offers

  • Background monitoring that detects restocks and instantly wakes the browser to buy
  • Per-item price limits, plus guards against markups, price spikes and third-party resellers
  • An append-only spend ledger that reserves funds before each order, so a crash can never undercount spending
  • Phone push notifications with remote approval from any device
  • Pre-run checks, post-purchase audits and a deduplicated error log
  • A reward system that scores runs and learns which page elements are most reliable
  • A real-time terminal console for tasks, activity, limits and approvals
  • Chromium, Firefox and WebKit support, each with a persistent signed-in profile

Why it stands apart

Every task starts in dry-run mode. Payment details are never seen or stored. CAPTCHAs are detected and handed to you, never evaded. Temporary limit increases expire automatically and can be revoked at any time. An extensive test suite runs the whole pipeline against a bundled mock store.
